# ⏱️ Counter App

A simple and interactive **Counter App** built using **HTML, CSS, and JavaScript (DOM Manipulation)**. The application automatically increments the counter every second and provides buttons to **Start**, **Stop**, **Resume**, and **Reset** the counter.

---



## ✨ Features

- ▶️ Start the counter
- ⏸️ Stop (Pause) the counter
- ▶️ Resume the counter
- 🔄 Reset the counter to 0
- ⏱️ Automatic counting every second
- 🎨 Clean and simple user interface
- 📱 Responsive design
- 📚 Beginner-friendly project

## ⚙️ How It Works

### ▶️ Start
- Starts the counter.
- The counter increases by **1 every second**.

### ⏸️ Stop
- Pauses the counter without resetting the value.

### ▶️ Resume
- Continues counting from the paused value.

### 🔄 Reset
- Stops the counter.
- Resets the counter value to **0**.
